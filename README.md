# Cook It Yourself (C.I.Y.)

A responsive meal-kit ordering website concept built as a student project.

## Run locally

Open `index.html` in a modern browser. The site uses remote Google Fonts and Unsplash images, so an internet connection is needed for those assets.

## Features

- Thai and English website content
- Responsive layout for desktop, tablet, and mobile
- Meal menu with category filters
- Ingredient picker for each meal
- Optional extras with additional prices
- Shopping basket with quantities and customizations
- Demonstration checkout form
- Newsletter interaction demo

## Important

This is a front-end student-project prototype. Checkout and newsletter interactions are demonstrations only. It does not process real payments, store orders, or arrange delivery. Do not enter real sensitive personal information.

## Deployment

The project is deployed at https://cook-it-yourself-cat-hub1.vercel.app/
